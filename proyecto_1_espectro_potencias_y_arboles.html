Proyecto: Contenido de información en el espectro de potencias usando métodos de árboles

¿Qué es el espectro de potencias? (para estudiantes no cosmólogos)

Supongamos que tenemos un campo fluctuante en el espacio, podría ser una temperatura en una habitación o en nuestro ejemplo la densidad de materia oscura del universo \[ \delta(\mathbf{x}) \equiv \frac{\rho(\mathbf{x})-\bar\rho}{\bar\rho}. \]

Una forma natural de describir cómo varía el campo en distintas escalas espaciales es transformarlo a espacio de Fourier: \[ \delta(\mathbf{k}) = \int d^3x\, e^{-i\mathbf{k}\cdot \mathbf{x}}\,\delta(\mathbf{x}). \]

El espectro de potencias se define (a parte convenciones) como la varianza de los modos de Fourier: \[ \langle \delta(\mathbf{k})\delta(\mathbf{k}')\rangle = (2\pi)^3\delta_D(\mathbf{k}+\mathbf{k})\,P(k), \quad k=|\mathbf{k}|. \]

La transformada de Fourier descompone un campo en ondas planas. Cada modo de Fourier representa una onda con longitud de onda \(2\pi/k\). Por lo tanto:

  • Escalas grandes: \(k\) pequeño (longitudes de onda largas).
  • Escalas pequeñas: \(k\) grande (longitudes de onda cortas).
  • \(P(k)\) indica cuánta “estructura” hay en cada escala.

En un experimento real no se mide \(P(k)\) continuamente, sino en bins: \[ P_b \equiv P(k_b), \] promediando dentro de un rango de \(k\) centrado en \(k_b\). Es decir

\[ P_b = \frac{1}{\Delta k_b}\int_{k_b-\Delta k_b/2}^{k_b+\Delta k_b/2} P(k) dk. \]

Objetivo del proyecto

Simularás mediciones tipo “survey” del espectro de potencias de materia oscura, binned y con covarianza Gaussiana, entrenarás métodos de árboles para inferir dos parámetros cosmológicos

\[ \theta = (\Omega_m,\ A_s), \]

y finalmente identificarás qué bins en \(k\) contienen mayor información sobre cada parámetro.

La idea central es invertir el flujo tradicional:

  • En lugar de calcular directamente una matriz de Fisher,
  • entrenarás un modelo de aprendizaje automático,
  • y usarás herramientas de importancia de variables para mapear la información en las escalas físicas.

Parámetros y rangos

  • Para cada muestra \(\Omega_m\) toma valores aleatorios en el rango \((0.20, 0.40)\)
  • \(A_s\) toma valores aleatorios en el rango \((1.5\times 10^{-9},\, 3.5\times 10^{-9})\)

Los demás parámetros se mantienen fijos:

  • \(h = 0.67\)
  • \(\Omega_b = 0.049\)
  • \(n_s = 0.965\)

Aproximación pedagógica explícita para el espectro de potencias

No se espera que uses un código numérico para simular el espectro de potencias. Utilizaremos un modelo analítico que es usado a veces en la literatura para entender el comportamiento del espectro de potencias.

Forma lineal básica

Tomamos:

\[ P_{\rm lin}(k;\theta) = A_s\,k^{n_s}\,T^2(k;\Omega_m), \]

donde la dependencia en \(\Omega_m\) entra a través de la función de transferencia BBKS:

\[ T(q) = \frac{\ln(1+2.34q)}{2.34q} \left[1+3.89q+(16.1q)^2+(5.46q)^3+(6.71q)^4\right]^{-1/4}. \]

Definimos

\[ q \equiv \frac{k}{\Gamma}, \]

con el parámetro de forma

\[ \Gamma(\Omega_m) = \Omega_m\,h\, \exp\!\left[-\Omega_b\left(1+\frac{\sqrt{2h}}{\Omega_m}\right)\right]. \]

Interpretación:

  • \(A_s\) controla principalmente la amplitud global.
  • \(\Omega_m\) modifica la forma del espectro (desplazando estructura en \(k\)).

Corrección no lineal pedagógica (opcional pero recomendada)

Para hacer más realista el comportamiento en escalas pequeñas, aplicamos un “boost” suave:

\[ P_{\rm nl}(k) = P_{\rm lin}(k) \left[1 + \left(\frac{k}{k_{\rm nl}}\right)^{\alpha}\right], \]

con valores fijos:

  • \(k_{\rm nl} = 0.25\ h\,{\rm Mpc}^{-1}\)
  • \(\alpha = 1.5\)

Esto hace que las escalas pequeñas tengan más potencia, lo que también hará que tengan mayor error. Esto ocurre en los datos reales, aunque no sigue esta forma sino una relación comolicada y difícil de calcular. Nos interesa aquí hacer un ejemplo fácil (pero fácil de extender a un espectro de potencias realista).

Binning y covarianza

Binning

Elegir:

  • \(k_{\min} = 0.01\)
  • \(k_{\max} = 0.5\) en unidades de \(h\,{\rm Mpc}^{-1}\)
  • \(N_b = 30\) bins logarítmicos

Definir:

  • bordes del bin
  • centros \(k_b\) (media geométrica)
  • \(\Delta k_b\)

Calcular \(P_b\) como el promedio dentro del bin. Esto se puede hacer promediando sobre muchos \(k\) dentro de cada bin.

Covarianza Gaussiana

Modelo base (diagonal):

\[ \mathrm{Cov}(P_b,P_{b'}) = \delta_{bb'}\,\frac{2\,P_b^2}{N_b^{\rm modes}}, \]

con

\[ N_b^{\rm modes} \approx \frac{V}{2\pi^2}\,k_b^2\,\Delta k_b. \]

Usar un volumen efectivo, por ejemplo

\[ V = 5\,(h^{-1}{\rm Gpc})^3. \]

Recordar que:

\[ 1\,(h^{-1}{\rm Gpc})^3 = 10^9\,(h^{-1}{\rm Mpc})^3. \]

Código para generar el espectro de potencias y los mocks

import numpy as np

h = 0.67
Omega_b = 0.049
n_s = 0.965

def gamma_shape(Omega_m):
    return Omega_m*h*np.exp(-Omega_b*(1+np.sqrt(2*h)/Omega_m))

def T_BBKS(k, Omega_m):
    Gamma = gamma_shape(Omega_m)
    q = k/Gamma
    L = np.log(1+2.34*q)/(2.34*q)
    C = (1+3.89*q+(16.1*q)**2+(5.46*q)**3+(6.71*q)**4)**(-0.25)
    return L*C

def P_lin(k, Omega_m, A_s):
    T = T_BBKS(k, Omega_m)
    return A_s * k**n_s * T**2

def P_nl(k, Omega_m, A_s, k_nl=0.25, alpha=1.5):
    return P_lin(k, Omega_m, A_s) * (1 + (k/k_nl)**alpha)

def make_kbins(kmin=0.01, kmax=0.5, nbins=30):
    edges = np.logspace(np.log10(kmin), np.log10(kmax), nbins+1)
    centers = np.sqrt(edges[:-1]*edges[1:])
    widths = edges[1:] - edges[:-1]
    return edges, centers, widths

Tareas a cumplir

Tarea A: Generar mocks

  1. Muestrear \((\Omega_m, A_s)\).
  2. Calcular \(P_b(\theta)\).
  3. Generar observaciones ruidosas. Para ello agréguele a cada bin un ruido gaussiano con varianza \(C_{bb}\).
  4. Separar en training y test.

Sugerencia:

  • \(N_{\rm train}=5000\) espectros de potencias ruidosos en el conjunto de entrenamiento.
  • \(N_{\rm test}=2000\) espectros de potencias ruidosos en el conjunto de test.

Donde \(N\) es el número de espectros de potencias generados, cada uno con diferentes valores de \((\Omega_m, A_s)\) y diferente realización del ruido.

Tarea B: Entrenar modelos de árboles

Entrenar al menos:

  • Random Forest Regressor
  • Gradient Boosted Trees

Entradas: \(\log \hat P_b\) en cada bin. Salidas: \((\Omega_m, A_s)\).

Pista: La escala de las variables que se intentan predecir es muy diferente, lo que puede ser problemático para algunos modelos. Encuentre una forma de resolver este problema.

Reportar:

  • RMSE
  • MAE
  • \(R^2\)
  • gráficos predicho vs real con residuales

Tarea C: Identificar bins informativos

Usar al menos dos métodos:

  1. Permutation importance (Investigar en qué consiste)
  2. Importancia por impureza (MDI) con feature_importances_ de árboles

Graficar:

  • Importancia vs \(k\) para \(\Omega_m\)
  • Importancia vs \(k\) para \(A_s\)

Interpretar físicamente:

  • ¿Dominan las escalas grandes o pequeñas?
  • ¿\(\Omega_m\) y \(A_s\) usan las mismas escalas?

Interpretación física (Tarea C)

Observa los gráficos:

  • ¿Dominan las escalas grandes o pequeñas? Mira dónde están los máximos en los gráficos (pequeño \(k\) o grande \(k\)).
  • ¿\(\Omega_m\) y \(A_s\) usan las mismas escalas? Compara los patrones entre los dos parámetros.
  • ¿Hay diferencia entre RF y GB? Ambos métodos deberían coincidir aproximadamente en qué bins son importantes.

Tarea D: Curvas de ablación

  1. Ordenar bins por importancia.
  2. Reentrenar usando solo los \(m\) bins más importantes.
  3. Graficar RMSE vs \(m\).
